# Gidar (قدار) - Mental Health Support Platform

## 🧠 What is Gidar?
Gidar is a secure, user-friendly web application designed to provide mental health support and connect users with professional specialists in a safe, confidential environment.

## 🛠️ Problems It Solves
1. *Accessibility to Support:* Bridges the gap between individuals seeking psychological guidance and certified specialists.
2. *Privacy & Confidentiality:* Provides a secure space for users to express their concerns and seek help without fear of judgment.
3. *Stigma Reduction:* Encourages mental health awareness and makes seeking professional support easier and more approachable.

## 🚀 Technologies Used
* *HTML5 & CSS3* for structure and styling.
* *JavaScript* for interactive features and dynamic behavior.
* *Supabase* for backend database and management.
